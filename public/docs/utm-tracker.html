Vicky UTM Tracker v1.0

Guía de integración para el equipo web de GeoVictoria — Atribución de leads desde WhatsApp

¿Qué hace este script?

Cuando un visitante llega a geovictoria.com desde un anuncio de Google Ads (o cualquier otro origen) y hace clic en el botón de WhatsApp para hablar con Vicky, el script captura automáticamente:

  • GCLID — ID de clic de Google Ads (clave para atribución server-to-server)
  • UTMs — utm_source, utm_medium, utm_campaign, utm_content, utm_term
  • Fuente orgánica — infiere Google/Bing/LinkedIn/directo si no hay UTMs
  • Landing Page — URL de la página de origen

Esos datos viajan con el prospecto hasta Zoho CRM, donde quedan registrados en los campos de Marketing del lead.

✅ No requiere modificar el código del botón de WhatsApp. El script lo detecta automáticamente.

⚡ Instalación — 1 línea de código

1

Agregar antes del </body> en todas las páginas que tengan botón de WhatsApp:

<script src="https://geovictoria-whatsapp-agent.vercel.app/vicky-utm-tracker.js"></script>
💡 Si el sitio usa Google Tag Manager, se puede agregar como tag HTML personalizado con trigger "All Pages".
2

Verificar que los botones de WhatsApp tengan uno de estos formatos (el script los detecta automáticamente):

<!-- Cualquiera de estos funciona -->
<a href="https://wa.me/56966765498">WhatsApp</a>
<a href="https://api.whatsapp.com/send?phone=56966765498">WhatsApp</a>
<a class="vicky-whatsapp-btn" href="#">WhatsApp</a>
<button data-whatsapp="true">WhatsApp</button>
3

Listo. No se necesita ningún otro cambio.

🔍 Cómo funciona

Tráfico de Google Ads

Cuando Google Ads trae un visitante, la URL tiene ?gclid=Cj0KCQ.... El script lo captura junto con los UTMs y los codifica en el primer mensaje de WhatsApp:

https://wa.me/56966765498?text=%5BREF%3AeyJ1dG1fc291cmNlIjoiZ29vZ2xlIiwiZ2NsaWQiOiJDajBLQ1EuLi4ifQ%3D%3D%5D

Vicky lee ese código invisible, lo decodifica y lo envía a Zoho CRM con el lead.

Tráfico orgánico y directo

Si no hay UTMs en la URL, el script infiere la fuente desde el referrer del navegador:

Google Ads (con GCLID)googlecpc

Sin referrer (directo)directdirect

✅ Cómo verificar que funciona

1

Abrir la página con un UTM de prueba en la URL:

geovictoria.com/cl/?utm_source=test&utm_medium=cpc&utm_campaign=prueba_script
2

Hacer clic en el botón de WhatsApp. El mensaje pre-escrito debería contener un texto que empieza con [REF:.

3

Enviar el mensaje a Vicky y completar la conversación hasta dar nombre, empresa y email. El lead creado en Zoho debería tener los campos de Marketing completos.
